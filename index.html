BizzCard

Install BizzCard

Flutter project by Ali Alsaffar

Android

Download the app and install it on your phone.

Download for Android (43 MB)
  1. Open the downloaded file.
  2. If asked, allow installing from this source.
  3. Tap Install, then Open.

iPhone

iPhone apps can't be installed from a web page, so this opens the same app in Safari.

Open BizzCard in the browser
  1. Tap Share in Safari.
  2. Tap Add to Home Screen to keep it as an icon.
Source code is in the private Gitea repo aalsaffar/bizz-card.
